# Rain Strap

Windows Roblox 启动器 · 作者 Qyuki_QAQ

此仓库只发布编译后的程序，暂不公开 Rain Strap 源码。GitHub 的 Source code 压缩包只包含此仓库的说明与许可文件，不包含启动器源码。

## 下载

请在 [Releases](https://github.com/Qyuki0907/RainStrap/releases) 下载 EXE，最新正式版为 [v1.0.1](https://github.com/Qyuki0907/RainStrap/releases/tag/v1.0.1)。保留 [v1.0](https://github.com/Qyuki0907/RainStrap/releases/tag/v1.0) 供需要的用户选择。

| 要求 | 说明 |
|---|---|
| 系统 | Windows；需要 .NET Framework 4.8 或更新版本 |
| 安装 | 将 EXE 放到可写文件夹并双击 |
| 资料 | 自动在 EXE 同级创建 RainStrapData，请保留整个文件夹 |
| 升级 | 退出旧启动器后替换 EXE，保留 RainStrapData |
| 网页接管 | 已接管 Roblox 网页启动时，移动或改名后需重新接管 |

v1.0.1 包含浏览器选择和文件改名启动修复。**当前发布的 v1.0 和 v1.0.1 均不含 Rain Strap 自身的自动更新**；启动 Roblox 时检查 Roblox 客户端版本属于另一个功能。启动器自动更新正在单独开发，计划随用户决定的后续版本发布。

发布资产附带 SHA256SUMS.txt，便于校验下载内容。发布文件不含作者账号、Cookie、私人服务器链接、歌单、背景或 Roblox 下载资料。
